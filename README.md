## 怎么选：三个问题帮你定位

**问题一：你的流量稳定吗？**

- 稳定、能预估 → 经典云，价格透明，配合"丙午"8折很划算

- 不稳定、忽高忽低 → 弹性云，按需调配置不浪费

**问题二：你预算多少？**

- 一年几百块的小项目 → 经典云 hk.mini（¥150/年）或 hk.cld.s（¥25/月）

- 月预算几十到两百 → 香港-KC 精品系列，配合"丙午"码
